# This Mac

A file browser for macOS that shows the whole machine as one tree, in the way Windows File Explorer does.

## Language

**This Mac**:
The single root of everything the app shows, and the page that lists every Drive and Quick Access folder.
_Avoid_: This PC, Computer, Home page

**Drive**:
A local storage volume that is currently mounted, shown with its used and free capacity.
_Avoid_: Disk, Volume, Partition

**Folder Tree**:
The expandable hierarchy that starts at This Mac and descends through each Drive into its Folders.
_Avoid_: Sidebar, Navigation pane

**Quick Access**:
A short fixed list of Folders the user reaches often, shown above the Drives.
_Avoid_: Favorites, Bookmarks, Shortcuts

**Folder**:
A container of Items that the user can navigate into.
_Avoid_: Directory

**Package**:
A directory that macOS presents as a single file, such as an application. It is an Item, not a Folder.
_Avoid_: Bundle

**Item**:
Anything listed inside a Folder: a file, a Package or another Folder.
_Avoid_: Entry, Node, Object

**Hidden Item**:
An Item that macOS marks as hidden. It is listed only when the user turns Hidden Items on.
_Avoid_: Dotfile, System file

**Address**:
The full path from the root of a Drive to the current Folder.
_Avoid_: Location, Breadcrumb, Path bar

**Details List**:
The table of Items in the current Folder, with Folders always above other Items.
_Avoid_: File list, Table view

**Preview Pane**:
The panel that shows the content of the selected Item without opening it.
_Avoid_: Inspector, Quick Look panel

**Cut**:
Marking Items to be moved. Nothing moves until the user Pastes.
_Avoid_: Move

**Paste**:
Completing a pending Copy or Cut into the current Folder.

**Conflict**:
A Paste where an Item with the same name already exists in the destination. The user chooses Replace, Keep Both or Skip.
_Avoid_: Collision, Duplicate

**Trash**:
The macOS Trash. Deleting an Item always moves it there, so it can be restored.
_Avoid_: Recycle Bin, Delete permanently
